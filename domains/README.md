# Earthkind domain assets

Use these assets with the Domain sub-brands sections in [Earthkind-Docs.md](../Earthkind-Docs.md) and [Earthkind-Decks.md](../Earthkind-Decks.md).

`tokens.json` holds the approved color pairings and component dimensions. The four SVGs are official Lucide icons, sourced from the [Lucide repository](https://github.com/lucide-icons/lucide/tree/main/icons). Their license is included in `LICENSE-LUCIDE.txt`.

Set SVG `currentColor` to the domain foreground token. Use the same foreground for Sen bold labels. Keep the Democracy outline on both cards and pills. Large cards use softly rounded corners; small labels use fully rounded pills. Render transparent component images at 3× or 4× their intended display dimensions if the document host cannot preserve the native rounded shape. Keep surrounding text editable.
